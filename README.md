# 2Dドット避けゲーム

## 1. 作品概要
HTML・CSS・JavaScriptを使用して制作した、ブラウザ上で遊べる2Dアクションゲームです。プレイヤーを操作して上から落下してくる敵を避け、できるだけ高いスコアを目指します。

## 2. 使用技術
- HTML5
- CSS
- JavaScript
- Canvas API
- PNG画像
- LocalStorage

## 3. 主な機能
- Canvasを使用したゲーム画面の描画
- キーボード・マウスによるプレイヤー操作
- 敵キャラクターの生成と落下処理
- プレイヤーと敵の当たり判定
- スコア表示とゲームオーバー処理
- スコアに応じた敵の速度調整
- 最高スコアの管理

## 4. 制作で工夫した点
ゲームの基本機能を実装した後、スコアに応じて敵の落下速度が上昇する仕組みを追加し、ゲームの難易度が段階的に高くなるよう工夫しました。

また、処理ごとに関数を分け、プレイヤーの移動、敵の生成、当たり判定、描画などの役割を整理しました。

## 5. 制作を通じて学んだこと
仕様の検討から実装、動作確認、エラーの修正まで、一連の開発工程を経験しました。ChatGPTも活用しながら、コードの役割や処理の仕組みを確認し、自分で理解を深めながら改善に取り組みました。

現在もプログラミングの学習を継続しており、今後はC#やUnityの習得を進め、ゲーム開発の技術力を高めていきたいと考えています。

## 6. 実行方法
1. リポジトリ内のファイルをダウンロードします。
2. `index.html` と `images` フォルダを同じプロジェクト内に配置します。
3. `index.html` をブラウザで開きます。
4. スタートボタンを押してゲームを開始します。

※画像が正しく表示されない場合は、`images` フォルダの位置とファイル名を確認してください。
